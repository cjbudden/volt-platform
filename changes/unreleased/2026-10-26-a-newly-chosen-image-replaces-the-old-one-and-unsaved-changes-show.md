Choosing a new image for an asset now replaces the old one straight away, everywhere it is shown. Before, a new frame could keep showing the old picture, and an image set in the Metadata form was ignored if someone had chosen the image by hand earlier. The Metadata form now also shows clearly when it has unsaved changes, and asks before you switch tab, open another asset or close it with changes unsaved.
