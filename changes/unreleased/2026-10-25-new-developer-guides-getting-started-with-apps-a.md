New developer guides: getting started with apps and keys, the play gate and playback tokens, playback reporting and the QoE API, notifications and webhooks, guide import and the EPG API, uploads, and recipes for common integrations. The authentication, lists and player SDK guides follow the same layout, and the player guide now covers DRM and playback reporting. Every code example in them is run against the Volt API before the documentation is published.
