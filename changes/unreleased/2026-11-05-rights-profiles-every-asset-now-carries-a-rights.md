Rights profiles. Every asset now carries a rights profile that sets where it may be shown, on which apps, for which uses (on demand, FAST and linear, clips, social, downloads, ads), with which access types and inside which window. Publishing, the play gate and FAST lineups never go outside it. Find it under Admin, Media setup, Rights, and on each asset's new Rights tab.
