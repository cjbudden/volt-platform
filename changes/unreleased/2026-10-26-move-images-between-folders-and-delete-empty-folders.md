In the Image Library you can now select images (tick them, or Shift-click a range) and move them to another folder, or drag them onto a folder in the tree. Everything that uses a moved image keeps working, including assets, channel slates and logos, metadata and links already shared. An empty folder can be deleted from its folder view; a folder that still holds images says how many and where.
