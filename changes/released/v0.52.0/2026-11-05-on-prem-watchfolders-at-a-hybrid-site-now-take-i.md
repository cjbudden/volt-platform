On-prem watchfolders at a Hybrid Site now take in images, slates, audio, captions and metadata files, not only video. The site agent uploads each accepted file and Volt takes it in as from a local folder; a caption sent to review is moved into the review folder at the site. New site folders get every default rule, and Add default rules gives older ones the rest. Update site agents to 0.4.0.
