Mac end-to-end run sheet: bash scripts/e2e-mac.sh walks the whole product path against the running Volt (start, captions, rights, failover, record, clip, VOD, publish, radio, event, FAST) and prints pass, fail or skip per step. The check suite e2e-runsheet keeps its API calls matched to the real routes.
