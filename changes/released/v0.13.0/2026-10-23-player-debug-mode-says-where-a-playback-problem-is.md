Debug mode on every player (right-click > Debug mode, Shift+D, or Cmd/Ctrl+D) now says where a problem is: this device or connection, access rules (region, sign-in), delivery, the stream itself, or the player. It also says whether the problem is worth reporting. A slow connection gets a short note on the picture, so viewers can tell it is their connection and not the stream.
