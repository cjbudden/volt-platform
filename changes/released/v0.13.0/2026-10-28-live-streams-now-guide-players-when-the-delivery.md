Live streams now guide players when the delivery path is nearly full: playlists suggest a fair highest bitrate (CMSD), so players step down before the link stalls everyone. A stream delivered over more than one path can steer each viewer's player to the path that works best where they are, measured from the players' own playback reports, without a stall when it moves.
