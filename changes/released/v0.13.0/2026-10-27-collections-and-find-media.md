Collections: group media your own way, nested as deep as you need (a collection per channel, a sub-collection for each week's playlist). Select media in the Media Library list or grid and add it to a collection, browse the library by collection from the new rail with every filter still working, and manage, order and remove collections on the new Collections page. In a FAST channel's run order, the library can add a whole collection in its order, and **Find media** opens the Media Library's full search and filters to add many titles at once.
