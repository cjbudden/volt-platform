## 1 · Admin · sign-in & my account

Admin users (a client's staff) sign in here. The access token is audience volt:admin.

### Sign in

`POST /api/auth/login`

Returns {access, refresh, expiresIn, amr} when no second step is due. If the user has two-step sign-in on, the answer is {mfaRequired, challenge, methods, email, phone} instead (see the "two-step" requests below). If the account requires it and the user has none, {mfaSetupRequired, challenge, available}. Rate limited per email and per address.

**API:** sign-in · **Credential:** none · **Access:** no session

| Parameter | In | Type | Required | Notes |
|---|---|---|---|---|
| `email` | body | string | yes | Admin user email. |
| `password` | body | string | yes | Password. |

**Request body**

```json
{
  "email": "{{adminEmail}}",
  "password": "{{password}}"
}
```

**Response `200`**

```json
{
  "access": "eyJhbGciOiJIUzI1NiIsInR5…(341 chars)",
  "refresh": "n69oftgEWUD2b_Oeb7598GVPsuLHTN-e-HYgf5Ybfxg",
  "expiresIn": 900,
  "amr": [
    "pwd"
  ]
}
```

### Refresh the session

`POST /api/auth/refresh`

New access token. Answers 401 code mfa_required when the account now requires two-step sign-in and this session did not use it.

**API:** sign-in · **Credential:** none · **Access:** no session

| Parameter | In | Type | Required | Notes |
|---|---|---|---|---|
| `refresh` | body | string | yes | The refresh token. It rotates: use the new one next time. |

**Request body**

```json
{
  "refresh": "{{adminRefresh}}"
}
```

**Response `200`**

```json
{
  "access": "eyJhbGciOiJIUzI1NiIsInR5…(341 chars)",
  "refresh": "Rvki8Kr4KzjJ2WoofiY7wU09aWQhBLnJzrCqIepB8rg",
  "expiresIn": 900
}
```

A named set of levels per feature.

**API:** admin · **Credential:** admin session (Bearer {{adminToken}}) · **Access:** access: manage
