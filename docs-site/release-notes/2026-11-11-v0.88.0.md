Changes to Captions, Console, EPG, FAST channels and Media Library.

<!-- truncate -->

## New

- **FAST channels:** FAST channel idents can now play after every few programmes instead of after every one: on the channel's Brand tab, choose Idents between programmes and set "Play an ident after every N programmes". The titles in between run back to back as a group and the ident closes it, which suits short titles. The ident lands in the same place on every re-plan, and the count starts again at the daily restart. Apply the lineup after changing it so the guide makes room.
- **Media Library:** Read from file name now splits the file name into its parts and lets you choose a field for each one, for names the reading misses: 21_josh-woodward_saboteurs_1080p.mp4 can fill Artist with Josh Woodward and Title with Saboteurs. For songs and music videos Volt suggests the artist and title for you to check.
- **Media Library:** Use this frame as the image: pause the preview on any frame and make it the asset's image. The exact frame is saved to the Image Library and is not replaced by an automatic pick.
- **Media Library:** Remove several assets at once from the Media Library bulk bar. The dialog lists what goes and what cannot (an asset in an active FAST lineup), you type the number to confirm, and everything goes to Storage > Recently removed with Undo. Library deletes, single or bulk, are now kept for 2 days before the hourly cleanup deletes them for good (VOLT_LIBRARY_TRASH_DAYS). A new account setting, off by default, sends bulk actions by people below administrator to an administrator or owner to approve first. In production storage the packaged HLS and DASH in the origin bucket now go into the bin too: before this they stayed in the bucket, still playable, and were never cleaned up.
- **Media Library:** Find details on any asset: on the Metadata tab, Find details looks the title up and shows what it found beside what the asset has. Films, episodes and every other content type search Wikidata, matched to your fields by their schema.org names; songs and music videos use Find song details. Only the fields you tick change, and each remembers where it came from.

## Improved

- **Console:** Numbers no longer shift as they change: every digit in the console and the player now takes the same width, so live clocks, counters and bitrates stay still and columns of figures line up.
- **EPG:** A guide now shows the image of its channel, station or event at the top and beside every programme in the List and Timeline views, unless the programme has its own image. Events show the image from their details in the EPG list too, and a station's guide is called a station guide.
- **Media Library:** Better automatic images for videos: Volt now looks at about three times as many frames, keeps the best twelve from different shots, and prefers clear, well-lit faces over close-ups of hands or empty rooms. Dark, moody frames with lit highlights are no longer thrown away as black. Use Rebuild from source to redo an existing asset.
- **Media Library:** Find song details now works on music videos too. A music video keeps its type and its picture; the album cover is offered, not chosen for you.

## Fixed

- **Captions:** Whisper captions now appear on servers that cannot add a GPU server, such as a single on-site server: a profile set to small or larger, the default, runs as base in the encoder instead of waiting for a GPU server that never starts. The Captions settings say which models run where.
- **Media Library:** Subtitle and metadata files dropped in the Media Library uploader are attached to their video by name, the way a watchfolder does it (Elephants_Dream_zh_tw.vtt goes with Elephants_Dream.mp4, in the same drop or already in the library), instead of each becoming a video queued to encode. A caption with no video named like it is shown as not attached, with the reason. Opening a VOD upload for a caption or sidecar file is now refused on every path, the API included. Lower case language names keep their region or script, so zh_tw, zh-hant and pt_br become Chinese (Taiwan), Chinese (Traditional) and Portuguese (Brazil) rather than plain Chinese or Portuguese.
