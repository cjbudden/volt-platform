## New

- **Account:** A new Captions page under Admin turns live captions on for the account, picks the engine (self-hosted Whisper or the Gladia service), and sets each output profile's caption languages, the language spoken, the delay that keeps captions in step with the picture, and the Whisper model. A profile used by a running stream is shown locked until that stream stops.
