## New

- **Media Library:** Find details now reads a page you paste as well as searching Wikidata: paste the link to a title's own page (a studio's film page, a broadcaster's episode page, a news article, a podcast episode) and Volt reads the details it publishes, maps them to the content type's fields and shows them to tick, each applied field remembering the page it came from.
