Changes to Media Library and Watchfolders.

<!-- truncate -->

## New

- **Media Library:** Audio files (MP3, WAV, M4A, AAC, FLAC) become audio assets: Volt encodes the sound alone to AAC, packaged as HLS and DASH, and the asset plays with the audio player. Uploads of audio files used to fail at the encode.
- **Watchfolders:** New watchfolders start with a fifth default rule, Audio to the Media Library, and a rule may send audio files to the Media Library. Older folders get it from Add default rules.
