Changes to API and Sites.

<!-- truncate -->

## New

- **API:** Sites API: GET and POST /api/sites, GET and PATCH /api/sites/\{id\}, enrolment tokens, and approve, reject and rotate-credential for a site's hosts. Without the Hybrid Sites add-on these answer 403 with the code licence_required.
- **Sites:** Hybrid Sites add-on: Admin, Sites lists your own locations running the Volt site agent, with each site's health, its servers (cores, memory, graphics cards and their encode sessions, free disk, versions, last contact) and a one-time enrolment token to add a server, which then waits for Approve or Reject. Offered only to accounts with the add-on.
