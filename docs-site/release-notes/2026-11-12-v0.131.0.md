Changes to Events and Loops & Fillers.

<!-- truncate -->

## Improved

- **Events:** Open on the Events list is blue, as on Channels, Radio, FAST and Recordings. On an event's page the programme guide sits under the players by default, as on a channel; a layout you customised stays as you set it.
- **Loops & Fillers:** The view, archive and delete buttons on each row sit in outlined, rounded boxes, like the row buttons on every other list.
