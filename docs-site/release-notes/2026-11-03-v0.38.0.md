Changes to FAST and Trick-play.

<!-- truncate -->

## New

- **Trick-play:** FAST channels with trick-play on now also offer a DASH trick-mode track, so DASH smart TVs show pictures while fast-forwarding. It is the keyframes of one smaller size of each title, made once per title and shared by every channel that airs it.

## Fixed

- **FAST:** A FAST channel airing titles whose DASH names its files by rendition id pointed DASH players at files that do not exist; those names are now resolved for each title.
