Changes to Recordings.

<!-- truncate -->

## Improved

- **Recordings:** Clips are cut faster: only the first and last few seconds are re-encoded and the middle is copied as recorded, so a long clip is ready about as fast as a short one at the recording's own quality.

## Fixed

- **Recordings:** On some sources a clip could repeat its first frame or lose its last. Clips now start and end on exactly the frames you mark.
