## New

- **Mirror and Archive:** Copy rules can now copy an item's HLS/DASH package to a folder at your site: tick HLS/DASH package on a storage target and every playlist and segment goes there as one folder that plays as it is, each file read back. The box says what it costs in room: usually about 1.7 times the original.
