Changes to Docs, Media Library, Radio and Recordings.

<!-- truncate -->

## New

- **Radio:** An operator can correct a now-playing log entry that was put in the wrong class: choose Song, Ad or Content in its Class column on the station's page. Volt keeps what it had said and who corrected it, and the API has the same with PATCH /api/radio/\{id\}/log/\{entryId\}.
- **Radio:** Stations can be deleted through the radio API too: DELETE /api/radio/\{id\}, with GET /api/radio/\{id\}/delete-impact to see what goes with it. Same rules as removing a station in the console: owners and administrators, and stop it first.

## Improved

- **Docs:** The Notifications, Monitoring and never-dark channel guides now list the stream alerts (encoder stopped, source unreadable, a minute on the slate, output timing) and the Media Library guides say the Ingest Queue button is in the top bar.
- **Recordings:** The Recordings search now finds a channel, station or event by a programme or song that aired inside its recordings, not only by its name, and says what matched and when (for example Played: a song title and the time it aired).

## Fixed

- **Media Library:** Set type and metadata for all is now offered beside What are you adding? before any file is added, so the type and fields can be set before Start as soon as added starts the upload.
