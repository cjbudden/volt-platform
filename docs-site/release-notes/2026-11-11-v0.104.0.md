Changes to Media Library.

<!-- truncate -->

## Changed

- **Media Library:** schema.org data (GET /api/vod/\{id\}/schema.org) lists a title's plain video addresses only for a token-free title or, where play tokens are not enforced, a title with no country, rights, payment, sign-in, DRM, referrer or streams condition. Every other title lists only its watch page, so the data is no way round the play gate.
