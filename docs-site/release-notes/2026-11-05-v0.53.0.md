## New

- **Sites:** Hybrid Sites: servers at a site can now take work that Volt sends to that site. Each server fetches its own site's jobs over HTTPS, reports progress, and moves files through short-lived links made for one job and one file; if a server goes quiet, the job passes to another approved server of the site.
