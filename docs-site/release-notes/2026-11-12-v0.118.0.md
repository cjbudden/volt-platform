Changes to FAST.

<!-- truncate -->

## New

- **FAST:** A FAST run order slot can now follow a collection: choose the collection in the library and Add as one slot. Each time the slot comes round it airs the collection's next title, in its order or shuffled without repeats, and titles you add to the collection join the guide without editing the run order. The slot says how many of the collection's titles can air on the channel and why the rest cannot.

## Fixed

- **FAST:** On a phone or narrow window, the FAST library no longer stays over the run order as you scroll down to it.
