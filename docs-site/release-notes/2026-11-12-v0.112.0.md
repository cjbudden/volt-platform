Changes to API and Media Library.

<!-- truncate -->

## New

- **API:** POST /api/vod/bulk/availability applies a preset or a set of fields as many assets' own publishing rule, or clears it, checking each asset as PATCH /api/vod/\{id\}/availability does; refused assets are listed with why, and ?dryRun=1 shows the result without saving.
- **Media Library:** Set the publishing policy of many assets at once: tick them, choose Publishing policy, and apply a preset or clear their own settings. Before you save shows how many can take it and names any a locked rule keeps as they are; the rest are saved, and published ones take the change up within a minute.
