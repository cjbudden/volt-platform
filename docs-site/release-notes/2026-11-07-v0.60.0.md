## New

- **Recordings:** With the Mirror and Archive add-on, copy rules can now archive your recordings to storage at your own sites: one file per programme (or per hour when a channel has no guide), picture and sound exactly as recorded, with a metadata file beside it. Tick Recordings under Archive copies in Publishing Rules.
