Changes to Uploads.

<!-- truncate -->

## Improved

- **Uploads:** On a cloud deployment with several servers, an uploaded or watch folder video is encoded by whichever server takes the work, and replacing a server no longer loses the original files it received.

## Security

- **Uploads:** On a cloud deployment, original upload files and upload parts in progress can no longer be fetched through the content delivery network.
