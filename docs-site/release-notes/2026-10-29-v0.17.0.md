Changes to Content Types and Publishing Rules.

<!-- truncate -->

## New

- **Publishing Rules:** Publishing Rules can now give a content type its own rule directly, and Add a social account opens Social accounts instead of API Keys.

## Improved

- **Publishing Rules:** Event, Radio, TV and FAST managers can now see and set the publishing rule of the streams they run, on each stream's Access tab, without Account settings access.

## Fixed

- **Content Types:** Choosing New type extending a second time for the same type now makes another copy (copy 2, copy 3) instead of failing because the name was taken.
