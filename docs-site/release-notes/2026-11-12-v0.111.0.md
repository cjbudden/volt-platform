Changes to Media Library and Publishing Rules.

<!-- truncate -->

## Improved

- **Media Library:** Before you save now checks a single item's own publishing rule too: whether it changes anything, conflicts such as DRM with MP4 download, and a confirmation before DRM changes on a published item.

## Fixed

- **Publishing Rules:** A single item's own publishing rule can no longer set a field that the account, its content type, its channel, event or station, or a metadata rule has locked. Before, the value was saved and then ignored; now the save is refused and says which rule locked it.
