## Improved

- **Hybrid Sites:** When a FAST channel needs a video from an Encode at site folder encoded again, Prepare now sends the encode to the site that keeps the original instead of reporting that there is no source.

## Fixed

- **Hybrid Sites:** When a site re-encoded a video, the copies already packaged for a FAST channel's ladder were removed with the old version; they are now kept.
