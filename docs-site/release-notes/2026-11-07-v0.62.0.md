Changes to API, Image Library and Mirror and Archive.

<!-- truncate -->

## New

- **Image Library:** Rename an image from the Image Library: open it and choose Rename. Everything that uses it, such as channel slates and asset posters, follows the new name, and links to the old name keep working.
- **Mirror and Archive:** Copy rules can now copy clips cut from a recording (clips, full-event replays and exports): tick Clips on a storage target and each clip's file goes there exactly as Volt made it, with a metadata file beside it, named Title-Channel-date-time, when the clip is made, when it is published or nightly.

## Fixed

- **API:** Renaming or moving an image with PATCH /api/files/\{id\} now updates everything that uses it and keeps its old address working, and renames all files of a video item together.
