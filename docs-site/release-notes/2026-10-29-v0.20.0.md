Changes to Captions and Channels.

<!-- truncate -->

## Fixed

- **Captions:** A channel's Subtitles settings change every stream on its output profile, so they can no longer be saved while another stream on that profile is running; the message names the streams to stop, as Admin > Captions does.
- **Channels:** A channel or event page whose guide has programmes, just none in the next few hours, now says Nothing in the guide around now and names the next (or last) programme, instead of No programme guide yet.
