Changes to Media Library.

<!-- truncate -->

## New

- **Media Library:** Exact frames through the API: ask for any frame of an on-demand asset by frame number, timecode or time, or any moment of a recording, and get that frame (not the nearest keyframe) as a signed image at the width you need. Each asset now has a frame index with its frame rate, frame count and timecode range.
