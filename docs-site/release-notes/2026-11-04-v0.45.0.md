## New

- **Workflows:** A Report tab on Workflows shows how each stage has done over the last 24 hours, 7 or 30 days: runs, error rate, retries, how long the work took (p50 and p95) and the most common error codes, drawn on the workflow map, with add-on runs and runs and errors per lane over time. Also in the API as GET /api/workflows/report.
