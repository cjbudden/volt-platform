Changes to API and Events.

<!-- truncate -->

## New

- **API:** New event routes matching the channel ones: `GET /api/events/{id}/access-check`, `GET /api/events/{id}/inputs/{inputId}/preview` and `POST /api/events/{id}/health/reset`.
- **Events:** The event page now has Clear QC, like the channel page: it resets the event's health after an earlier fault, and the fault stays in the event log.

## Fixed

- **Events:** On the event page, 'View as a viewer in' now answers for the event instead of showing Could not check, and an HLS source that blocks playback from other sites now previews through Volt.
- **Events:** The event page no longer goes blank once a live event's output starts playing.
