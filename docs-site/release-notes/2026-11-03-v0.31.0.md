Changes to API and Account settings.

<!-- truncate -->

## New

- **Account settings:** Trick-play for Apple and smart-TV players: an optional switch per output profile (off by default) that lists I-frame playlists for on-demand media, so Apple devices, Safari and many smart TVs show pictures while scrubbing and fast-forwarding. Made from the segments Volt already has, with no re-encode.
- **API:** PATCH /api/output-profiles/\{id\} turns trick-play on or off (trickPlay); PATCH /api/account-settings takes trickPlayDefault, what new output profiles start with.
