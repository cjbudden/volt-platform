Changes to VOD.

<!-- truncate -->

## Fixed

- **VOD:** On a cloud deployment, clips and encoded files play and download from every server, and downloading an encoded MP4 no longer says the file is gone.

## Security

- **VOD:** The original file of an upload or watch folder drop can no longer be fetched through the media address by someone who knows the item's id.
