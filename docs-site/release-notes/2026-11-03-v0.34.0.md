Changes to Trick-play.

<!-- truncate -->

## New

- **Trick-play:** With trick-play on, on-demand media now also offers a DASH trick-mode track, so smart TVs and other DASH players show pictures while fast-forwarding and scrubbing. It is made from the files Volt already has, with nothing re-encoded or stored, and encrypted media keeps its protection.

## Fixed

- **Trick-play:** Encodes with several video renditions listed the same keyframe list for every rendition in HLS, so Apple players could show the wrong size of picture while scrubbing. Each rendition now has its own.
