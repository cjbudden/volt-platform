Changes to Sites.

<!-- truncate -->

## New

- **Sites:** Mirror and Archive (add-on): keep a copy of an asset's original on a folder or NAS share at one of your sites. Each copy counts only once the checksum read back from your storage matches the original, and a check finds a copy that later changed or went missing. Set up through the API for now.

## Changed

- **Sites:** Sites and their servers are now available with either the Hybrid Sites or the Mirror and Archive add-on; on-prem watchfolders still need Hybrid Sites.
