Changes to Watchfolders.

<!-- truncate -->

## New

- **Watchfolders:** A rule can send images straight into Loops & Fillers as slates (target kind filler-slate), ready for a channel or event to show when its input drops.
- **Watchfolders:** Artwork finds its episode: an image dropped into a watchfolder with a type word at the end of its name, such as Scrubs-s1-e1_poster.png or Scrubs-s1-e1-thumbnail.jpg, becomes that video's Poster or Thumbnail, as if chosen on the asset page. A rule can also give every image it takes an image type.

## Improved

- **Watchfolders:** Try a filename now shows the image type a file would get, and the video an image or caption would be attached to.
