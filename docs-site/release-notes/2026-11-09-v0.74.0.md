Changes to Documentation.

<!-- truncate -->

## New

- **Documentation:** New guide, Copies of your media at your own sites: Mirror and Archive from end to end, from a site and a storage target through copy rules to verified copies, with object-store keys, recordings in the archive, re-checks, troubleshooting and the API in one place. The Sites guide now points to it.
- **Documentation:** New page, Running a site, for whoever runs the servers at a site: installing and enrolling the agent, running it as a service, upgrading, credentials, shares and storage, reading its logs, and what to check when a site goes quiet.

## Fixed

- **Documentation:** The API reference no longer shows a raw storage address in the storage targets description, the Collections guide renders again, and a broken link in the on-demand ads guide is fixed.
