Changes to API, Media Library and Playback.

<!-- truncate -->

## New

- **Playback:** Operators can now enforce play tokens: with VOLT_EDGE_TOKENS=enforce (edge_tokens = "enforce" on AWS), a plain on-demand address with no token is refused at the CDN, the staging edge and the API, so the play gate's address is the only one that plays.

## Improved

- **API:** The API reference now describes the play gate's 451 answer (code, message, notify), Notify me (POST /api/public/availability/notify), the rights demand report (GET /api/analytics/rights-demand) and the preview addresses on GET /api/vod/\{id\}.
- **Media Library:** Previews in the Media Library and Skip markers, and share pages, play through play tokens, so they keep working when tokens are enforced. A share page's video stops when the link expires or the title's window ends, whichever is first, and plays in the country where it was opened.
