Changes to API, Ingest Rules, Media Library and Storage.

<!-- truncate -->

## New

- **Media Library:** The Media Library guide now covers deleting an asset: what goes with it, typing the title to confirm, and getting it back from Storage > Recently removed.

## Improved

- **Ingest Rules:** Each ingest rule's summary now reads in words, for example "when the extension is mov or mp4: metadata: Before upload". Greyed cloud drive buttons, here and in the upload panel, say your Volt provider sets them up instead of naming server settings.
- **Media Library:** When an asset has no file to download, its Encode tab now says why and how to get one: cut the clip again with an Output that includes a downloadable file, or upload the file as H.264 video with AAC sound in MP4 or MOV.
- **Storage:** Storage names each tier by what it does (Server disk, Standard, Infrequent access, Archive, Deep archive) and explains a refused retention ladder in the page's own words. The storage driver, its server setting and each copy's storage address are shown only to whoever runs your Volt service.

## Fixed

- **Media Library:** A role with Files, uploads & storage: Manage, such as the Media Librarian template, can now upload files, import a link and settle held files. Adding a file no longer needs Account settings: Manage.

## Changed

- **API:** GET /api/workflows/map no longer returns each stage's impl field. The ingest lookups POST /api/ingest/preview, POST /api/ingest/sanitise, GET /api/ingest/baseline and GET /api/ingest/providers now need Files, uploads & storage: View or Account settings: View. Storage locations carry their uri only for whoever runs the Volt service.
