Changes to API, Sites and Watchfolders.

<!-- truncate -->

## New

- **API:** GET /api/watchfolders/site-options, and on-prem watchfolders through POST /api/watchfolders with kind site, siteId, placement (upload_cloud) and the folder's path on the site's server.
- **Sites:** The site agent (0.3.0) watches the site's on-prem watchfolders beside its heartbeat, and Reprocess on a refused file asks it to move the file back into the folder.
- **Watchfolders:** With the Hybrid Sites add-on, a watchfolder can be on your own storage at a site. The site's agent sorts it with the folder's rules, keeps refused files in the review folder at the site, and uploads accepted video to Volt to be encoded; an interrupted upload carries on where it stopped.
