Changes to Mirror and Archive.

<!-- truncate -->

## New

- **Mirror and Archive:** Copy rules can now mirror a storage target: when an item is deleted from Volt and leaves the restore bin, its copies at that target are deleted too, after a waiting period you set per target (7 days by default, 0 to 90). Volt never deletes a file someone changed at your site, recordings are always kept, a restore cancels anything waiting, and every delete is in the audit trail.
- **Mirror and Archive:** The Storage page shows each target's mirror waiting period and the deletes waiting there, and each copy says when it will be deleted or that it was removed. Publishing Rules has a Keep choice per target: Archive or Mirror.
