Changes to FAST and VOD.

<!-- truncate -->

## Fixed

- **FAST:** On a cloud deployment, a new ad creative and a slate or loop used on a FAST channel are prepared by whichever server picks up the work, so they no longer fail when that is not the server that downloaded or rendered them.
- **VOD:** On a cloud deployment, caption tracks of a clip or encode stay in time with the picture when the server answering does not hold the video files.
