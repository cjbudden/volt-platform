On air + public delivery URL
🧪 Ready to test 📱 In app
On air is a real backend state (channels.on_air), separate from the encoder being up. Going on air is refused until the packaged output has valid content; stopping the channel takes it off air. A gated public URL /live/:id/master.m3u8|manifest.mpd returns the stream ONLY when on air with valid content (off air => 404, on air but broken => 503, else 302 to CloudFront in prod / origin locally). The On-air gate is honest: READY (blue) private, ON AIR (green) when truly serving valid content, FAILED (red) when published but broken.
tsc clean both apps; gate + route logic wired to ground-truth manifest freshness.
How to test: Start a channel, confirm output previews as READY, click Go on air (disabled until output is valid), open the public HLS/DASH links in the banner; Take off air => links 404.
